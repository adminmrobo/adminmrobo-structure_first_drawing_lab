# 구조 먼저 보는 캐릭터 그리기 연구실

> 픽셀 캐릭터를 실사까지 — 구조 → 빛 → 주름 순서로 그리는 원리를 실험으로 익히고, 그 원리로 AI 그림 프롬프트를 조립합니다.

**사이트:** https://adminmrobo.github.io/adminmrobo-structure_first_drawing_lab/

사람은 그림을 한 번에 그리지 않습니다. 상자와 원기둥으로 구조를 잡고, 빛을 정하고, 천을 얹습니다. 3D 렌더링도, 그림 생성 AI도 같은 순서로 움직입니다. 이 연구실에서는 이 원리로 연구실의 픽셀 캐릭터 하루·시아·모아를 애니풍과 실사풍으로 데려갑니다.

## 등장인물
| 역할 | 캐릭터 |
|---|---|
| 모델 | 조수 하루(1·4부), 인턴1 시아(2부), 인턴2 모아(3부), 5·6부는 셋 모두 |
| 화가 | 주판봇(성급하게 결과부터), 초파리 연구원(구조부터 의심) |
| 평가단 | X1·X2·X3 |
| 해설 | 박사 |

## 구성
| 부 | 페이지 | 다루는 것 |
|---|---|---|
| 목차 | `index.html` | 읽는 순서, 큰 그림(앞 부의 한계 → 다음 부의 이유), 등장인물 |
| 1부 | `01_structure.html` | 도형으로 단순화, 원기둥 고리선(sin), 돌려 보기(3D 마네킹), 원근 간격, 레이어 쌓기 |
| 2부 | `02_light.html` | 밝기 = cos θ, 입체·떨어지는 그림자, 섬 그림자, 그림자 흐림·반사광, VFX 렌더 층 |
| 3부 | `03_folds.html` | 당김·모임·처짐 주름(천 시뮬레이션), 주름 자리, 흐름과 꺾임, 굽힘과 남는 천(rθ) |
| 4부 | `04_ai_learns.html` | 비슷한 그림 묶기(K-평균), 잠재공간, 확산 모델, 안내 강도 |
| 5부 | `05_pixel_to_real.html` | 캐릭터 고정 문장, 화풍 바꾸기, 원본 반영 강도, 포즈·선화·깊이 가이드, 프롬프트 조립 실습 |
| 6부 | `06_failure_lab.html` | 의도적 실패 8종 진단(증상 → 원인 → 원리 → 고치는 프롬프트) |
| 7부 | `practice/index.html` | 실전 연습장: 촬영 스튜디오·의상실·프롬프트 공방·진단 데스크 |

모든 실험은 외부 라이브러리 없이 동작하며, 그림 파일이 없어도 페이지가 완성 상태입니다.

## 그림
- 본문 그림 40장은 Genspark로 만듭니다. 요청문: `docs/image_requests/` (대화 C01~C11, 저장 이름은 `checklist.csv`).
- 받은 그림은 `assets/img/{이름}.webp`로 넣고 `python3 build/build.py`를 다시 돌리면 '그림 준비 중' 자리가 채워집니다. 표지가 들어오면 `python3 build/make_og.py`로 공유 미리보기를 다시 만듭니다.
- 이 시리즈만 본문 그림에 애니풍·반실사·실사풍을 허용합니다(표지는 픽셀아트). 실사풍은 캐릭터를 코스프레한 가상의 성인 모델이며 실존 인물이 아닙니다.

## 빌드와 점검
```
python3 build/build.py          # 페이지 만들기
python3 build/check_numbers.py  # 본문 숫자 검산
python3 build/make_og.py        # 공유 미리보기 그림
python3 build/check_missions.py # 실전 연습장 미션 판정 점검 (로컬 서버 8765번 필요)
```

## 원리와 출처
1~3부의 그리기 원리는 일반적인 드로잉 원리이며, 다테 나오토 『デジタルツールで描く！服のシワと影の描き方』(マイナビ) 1장 기본편을 참고해 정리했습니다. 책의 그림·문장·도식은 옮기지 않고 연구실 캐릭터와 실험으로 새로 구성했습니다. AI 원리는 DDPM(Ho et al., 2020), Classifier-Free Guidance(Ho & Salimans, 2022), SDEdit(Meng et al., 2021), ControlNet(Zhang et al., 2023)을 바탕으로 쉽게 풀었습니다. 전체 목록은 각 페이지 바닥글에 있습니다.
