## 1. 이번 시리즈만의 그림 규칙

## 6. 돌려주는 법
- 받은 그림을 `checklist.csv`의 `file` 이름 그대로(png·jpg) 저장해 zip으로 주세요. 한 번에 어려우면 **대화 단위(C01~C11)로 나눠** 여러 zip으로 주셔도 됩니다.
- 제가 WebP로 바꿔 `assets/img/{이름}.webp`에 넣고 다시 빌드하면, 각 페이지의 '그림 준비 중' 자리가 그림으로 바뀝니다(`page` 열이 들어갈 페이지).
- 표지(cover_*)가 들어오면 공유 미리보기(og)도 표지에서 잘라 다시 만듭니다.
- 받는 순서 추천: **C03(기준 전신) → C01·C02(표지) → 나머지**. C03이 이후 그림의 참고 그림이기 때문입니다.
