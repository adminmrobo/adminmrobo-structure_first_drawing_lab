## 규칙
- 문장을 고치지 말고 그대로, **첫 결과를 그대로** 저장(독자가 넣었을 때 나올 법한 결과를 보여 주기 위해서).
- 다시 만드는 경우: 노출, 실존 인물·유명 캐릭터 닮음, 그림 안 글자, 출발 그림과 전혀 다른 장면.
